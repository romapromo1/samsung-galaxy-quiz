# Kiosk-квиз Samsung Galaxy × New Star Weekend 2026

Интерактивное веб-приложение для проведения квиза на брендированных устройствах **Samsung Galaxy Z Fold8** и **Samsung Galaxy Z Fold8 Ultra** в полной развертке в режиме **Kiosk**.

---

## 🚀 Особенности и возможности

1. **Банк из 170 вопросов**:
   - Полностью импортирован из файла `Samsung_NSW26_вопросы для квиза.xlsx` с валидацией и нормализацией ответов.
   - Вопросы разделены по тематикам (Samsung Galaxy, технологии, фестиваль New Star Weekend).
   - Варианты ответа (A, B, C) перемешиваются при показе, чтобы исключить угадывание по расположению.

2. **Строгая логика сессий (без повторов)**:
   - Внутри одной сессии ни один вопрос не повторяется.
   - **Сессия n+1**: строго **0 вопросов** из сессии **n**.
   - **Сессия n+2**: максимум **2 вопроса** из сессии **n**.
   - Две предыдущие сессии сохраняются в `localStorage` устройства.

3. **Сценарий игры (Flow)**:
   - Экран Welcome с крупной кнопкой **PLAY**.
   - Всплывающее окно подсказки: *«Ответьте на максимальное количество вопросов за 60 секунд. Если готовы, жмите "СТАРТ"»*.
   - Обратный отсчет: **3... 2... 1... Вперёд!**
   - 60-секундный раунд с живым таймером и счетчиком правильных ответов.
   - Финальный экран результатов: общее число верных ответов, процент точности, конфетти и кнопка «Сыграть ещё раз».

4. **Адаптив под Z Fold8 и Fold8 Ultra**:
   - Специальный режим Kiosk: заблокированы случайные свайпы, зум пальцами и контекстное меню.
   - Крупные контрастные кнопки (высота 70–85px), рассчитанные на удобный хват двумя руками.
   - Верхняя панель переключения:
     - **Auto**: адаптив под реальный физический планшет на весь экран.
     - **Fold 8**: симуляция рамки и пропорций экрана 7.6" (2160×1856).
     - **Fold 8 Ultra**: симуляция рамки и пропорций экрана 8.0" (2184×1968).
     - Полноэкранный режим (⛶) и панель проверки памяти.

## 🌐 Деплой на Vercel

Приложение идеально подходит для Vercel (статический SPA на Vite):

### Вариант 1: Через GitHub (рекомендуется)
1. Создайте репозиторий на GitHub и загрузите файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   git push -u origin main
   ```
2. Откройте [vercel.com](https://vercel.com) и нажмите **Add New Project**.
3. Импортируйте ваш репозиторий.
4. Параметры сборки определяются автоматически:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Нажмите **Deploy**. Через 30 секунд проект будет доступен по ссылке `https://<project-name>.vercel.app`.

## 📱 Сборка и установка на устройства Samsung

Приложение можно запустить на смартфонах и планшетах Samsung двумя способами:

### Способ 1: PWA (Рекомендуемый, без установки через кабель)
1. Опубликуйте проект на Vercel (или запустите локально в Wi-Fi сети).
2. Откройте ссылку на **Samsung Galaxy Z Fold8 / Ultra** в браузере **Samsung Internet** или **Chrome**.
3. Нажмите в меню браузера **«Установить приложение»** (или «Добавить на главный экран»).
4. Приложение установится на рабочий стол устройства с логотипом Galaxy Quiz:
   - Запускается на **полный экран** (без адресной строки и рамок браузера).
   - Работает **100% офлайн** (кэшируется через Service Worker).
   - Для блокировки терминала включите в One UI: *Настройки -> Безопасность -> Другие параметры -> Закрепление приложения (Pin App)*.

### Способ 2: Сборка нативного Android APK (через Capacitor)
В проект уже интегрирован проект Android (`android/`):
```bash
# 1. Пересобрать проект и синхронизировать ассеты
npm run cap:sync

# 2. Открыть проект в Android Studio для генерации APK
npm run cap:open
# В Android Studio: меню Build -> Build Bundle(s) / APK(s) -> Build APK(s)
```
Либо воспользуйтесь сервисом [pwabuilder.com](https://www.pwabuilder.com/) — вставьте ссылку вашего Vercel-деплоя и скачайте готовый APK в один клик.

```bash
npm install

# Запуск локального сервера разработки
npm run dev

# Проверка сборки
npm run build

# Локальный предпросмотр продакшн-сборки
npm run preview
```

## 🧪 Тестирование логики повторов

В проекте есть автоматический стресс-тест сессий:
```bash
node scripts/test_session_logic.js
```
Скрипт симулирует 100 сессий подряд и проверяет отсутствие нарушений правил $n-1$ и $n-2$.
